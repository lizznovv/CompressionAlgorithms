# CompressionAlgorithms

Implementation of classic lossless compression algorithms and text transformations in Python.

## Implemented Algorithms

### Transformations
- Burrows-Wheeler Transform (BWT)
- Move-to-Front (MTF)

### Compression Algorithms
- Run-Length Encoding (RLE)
- LZ77
- LZ78
- Huffman Coding

### Combined Pipelines
- BWT + MTF
- BWT + RLE
- BWT + MTF + RLE + Huffman
- LZ77 + Huffman
- LZ78 + Huffman
